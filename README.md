# PadHUI — Xbox controller → Pro Tools surround panner

Emulates a HUI control surface over a virtual MIDI port so an Xbox controller can move Pro Tools' native 5.1 / 7.1.4 / Atmos panner. Work in progress.

**Source code and notes are in [`padhui-xbox-protools-panner/`](padhui-xbox-protools-panner/)** — see its [README](padhui-xbox-protools-panner/README.md).
